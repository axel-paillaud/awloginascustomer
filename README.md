# AwLoginAsCustomer

PrestaShop 9 module by [Axelweb](https://axelweb.fr): lets an employee log in to the front-office as a customer,
from the customer or order page of the back-office.

## Requirements

- PrestaShop 9.0+
- PHP 8.1+
- Composer

## Installation

```bash
composer install --no-dev
```

Then install the module from the back-office (Modules > Module Manager).

## Build

```bash
cd bin && ./build-zip.sh
```
